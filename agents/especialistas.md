# Especialistas sob demanda

Ativados pelo Orquestrador conforme o projeto (modelo *enabling team*). Ver [Papéis de agentes](../knowledge/organizacao/papeis-de-agentes.md).

| Especialista | Quando ativar | Entrega principal | Conhecimento ([ROADMAP](../knowledge/ROADMAP.md)) |
|---|---|---|---|
| Segurança (AppSec) | Projetos com dados pessoais; antes de cada release | Modelagem de ameaças, revisão SAST/SCA, parecer de release | #8 Segurança, #15 LGPD |
| UX/UI Designer | Interface nova ou design system | Fluxos, protótipos, design system | #13 UX/UI e acessibilidade |
| Dados / IA | Analytics, ML ou LLM | Pipelines de dados, modelos, componente "como serviço" | #12 Bancos de dados |
| Documentação Técnica | Entrega ao cliente, APIs públicas | Manuais, docs de API, guias | #11 Design de APIs |
| Pesquisador | Contínuo, um tema do ROADMAP por sessão | Novo documento em `knowledge/` | [ROADMAP](../knowledge/ROADMAP.md) |

Definições completas serão criadas quando o especialista for ativado pela primeira vez.
