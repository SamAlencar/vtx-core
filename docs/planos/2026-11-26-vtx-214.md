# Portão de merge sem proteção de branch (VTX-214) Implementation Plan

**Goal:** `scripts/mesclar_pr.sh <n>` só chama `gh pr merge` com CI verde e veredito na HEAD exata, e passa a ser o único caminho de merge previsto no AGENTS.md.

**Tech Stack:** bash, jq, gh, unittest com `gh` simulado no PATH.

**Spec:** auditoria técnica de 25/11/2026 §4 P1 item 12.

## Review Focus

- Check vermelho ou pendente: sai ≠ 0 e não chama merge.
- Sem veredito na HEAD, ou PR sensível sem aval delegado: não mescla.
- CI verde + veredito adequado: chama `gh pr merge --squash --match-head-commit`.
