# Portão de merge sem proteção de branch (VTX-214)

**Objetivo:** `scripts/mesclar_pr.sh <n>` só chama `gh pr merge` com CI verde e veredito na HEAD exata, e passa a ser o único caminho de merge previsto no AGENTS.md.

**Ferramentas:** bash, jq, gh, unittest com `gh` simulado no PATH (o stub recusa campos `--json` que o gh real não tem; o caso verde usa uma captura real de `gh pr checks`).

**Especificação:** auditoria técnica de 25/11/2026 §4 P1 item 12.

## Foco da revisão

- Check vermelho, cancelado ou pendente: sai ≠ 0 e não chama merge.
- Sem veredito no formato `**Veredito: …** (HEAD \`<sha>\`)` na HEAD, «Aprovado com ressalvas» nessa HEAD, ou PR sensível sem aval delegado: não mescla.
- CI verde + **Aprovado** (ou aval delegado): chama `gh pr merge --squash --match-head-commit`.
- Comentários depois dos 30 primeiros só entram com `gh api --paginate`.
